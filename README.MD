
# Sistema de Auditoría Automatizada

Proyecto desarrollado para el área de Planning.

## Descripción
Sistema basado en reglas para auditar datos operativos del proceso de abastecimiento,
identificando inconsistencias y generando alertas automáticas.

## Tecnologías
- Python
- Flask

## Funcionalidades
- Carga de datos CSV / Excel
- Validación y limpieza de datos
- Motor de auditoría basado en reglas
- Generación de reportes y alertas
